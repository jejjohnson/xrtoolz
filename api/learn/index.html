    scikit-learn on xarray (xrops.learn)¶

    The stack has one scikit-learn bridge: pipekit-array's Estimator, with to_rows / from_rows, which chooses samples by dim name on any carrier (geostack OP-O3). On a single DataArray in a pipeline, use it directly.

    xrops.learn adds what is xarray's own. XarrayEstimator puts a Dataset's variables side by side as one feature table, each on its own grid, and fits a DataTree per node or pooled over its nodes. Importing xrops.learn registers the .sklearn accessor on DataArray, Dataset and DataTree. scikit-learn is imported when an estimator is fitted, so install the xrtoolz-ops[sklearn] extra.

    XarrayEstimator ¶

    XarrayEstimator(estimator: Any, *, sample_dims: Hashable | Sequence[Hashable], feature_dim: str | None = None, nan_policy: NanPolicy = 'propagate', method: str = 'transform', tree_mode: TreeMode = 'per_node')

    Bases: Operator

    A scikit-learn-style estimator fitted and applied on xarray objects.

    The sample dims are chosen by name; every other dim of a variable is a feature. A Dataset's variables are put side by side as the columns of one table, so each may have its own feature grid. Outputs come back as:

    • one value per sample (predict): a DataArray over the sample dims;
    • the fitted features (a scaler, inverse_transform): the input's variables on their own grids, as a DataArray or a Dataset;
    • a new output dim (PCA scores, predict_proba): one DataArray with feature_dim where the first variable's feature dims were.

    Parameters:

    Name Type Description Default
    estimator Any

    Any object with scikit-learn's fit and the methods you call. It is cloned on fit; the original is never fitted.

    		 required
    sample_dims Hashable | Sequence[Hashable]

    The dim (or dims) whose entries are samples.

    		 required
    feature_dim str | None

    The name of a new output dim, for estimators whose output columns are not the input's features ("component" for PCA). predict_proba defaults to "class".

    		 None
    nan_policy NanPolicy

    "propagate", "raise", "mask_samples" or "mask_features", as in pipekit_array.Estimator.

    		 'propagate'
    method str

    What calling the operator runs once fitted: "transform", "predict" or "predict_proba".

    		 'transform'
    tree_mode TreeMode

    What fitting on a DataTree means: "per_node" fits one estimator per node (nodes may have different grids); "pool_samples" fits one on every node's samples (nodes share their variables and feature grids).

    		 'per_node'

    Example

    Decompose a (time, lat, lon) cube with PCA and recover the grid:

    >>> import numpy as np
>>> import xarray as xr
>>> from sklearn.decomposition import PCA
>>> rng = np.random.default_rng(0)
>>> da = xr.DataArray(rng.normal(size=(8, 3, 4)), dims=("time", "lat", "lon"))
>>> est = XarrayEstimator(PCA(3), sample_dims="time", feature_dim="component")
>>> scores = est.fit(da).transform(da)
>>> scores.dims, scores.shape
(('time', 'component'), (8, 3))
>>> est.inverse_transform(scores).dims
('time', 'lat', 'lon')
>>> est.estimator_.components_.shape
(3, 12)

    Scale every variable of a Dataset on its own grid:

    >>> from sklearn.preprocessing import StandardScaler
>>> ds = xr.Dataset({"u": da, "v": da.isel(lat=0)})
>>> scaler = XarrayEstimator(StandardScaler(), sample_dims="time")
>>> out = scaler.fit(ds).transform(ds)
>>> {name: out[name].dims for name in out.data_vars}
{'u': ('time', 'lat', 'lon'), 'v': ('time', 'lon')}

    def __init__(
    self,
    estimator: Any,
    *,
    sample_dims: Hashable | Sequence[Hashable],
    feature_dim: str | None = None,
    nan_policy: NanPolicy = "propagate",
    method: str = "transform",
    tree_mode: TreeMode = "per_node",

        (sample_dims,)

    self.layout_: Layout | None = None

    def fit(self, x: xr.DataArray | xr.Dataset | xr.DataTree, y: Any = None) -> Self:
    """Learn the estimator from ``x`` (and ``y``, for a supervised one).

    Args:
        x: A DataArray, Dataset or DataTree with the sample dims.
        y: Targets: a DataArray over the sample dims (plus at most one
            target dim); for a DataTree, a DataTree with one variable
            per node or ``{path: DataArray}``.

    Returns:
        This operator, fitted.

    Raises:
        ValueError: A variable lacks a sample dim, or (``"pool_samples"``)
            the nodes do not share their feature grids.
    """
    self.fitted_ = self.layout_ = self.estimators_ = None
    if isinstance(x, xr.DataTree):
        nodes = _nodes(x)
        if self.tree_mode == "per_node":
            self.estimators_ = {
                path: self._node_estimator().fit(ds, _node_target(y, path))
                for path, ds in nodes.items()
            }
            return self
        tables, targets, layout = [], [], None
        for path, ds in nodes.items():
            table, layout, samples = pack(ds, self.sample_dims, layout)
            tables.append(table)
            target = _node_target(y, path)
            if target is not None:
                targets.append(pack_target(target, samples))
        assert layout is not None
        self._fit_table(
            concat_tables(tables),
            concat_tables(targets) if targets else None,
            layout,
        )
        return self
    table, layout, samples = pack(x, self.sample_dims)
    self._fit_table(table, None if y is None else pack_target(y, samples), layout)
    return self

    def inverse_transform(self, z: xr.DataArray | xr.Dataset | xr.DataTree) -> Any:
    """Map ``transform``'s output back to the fitted variables and grids.

    def fit_transform(
    self, x: xr.DataArray | xr.Dataset | xr.DataTree, y: Any = None
) -> Any:
    """``fit(x, y)`` then ``transform(x)``.

    This is ``transform`` of the fitted estimator, not scikit-learn's
